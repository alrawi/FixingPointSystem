These are results of the reference stack from the sandbox, labelled as such. The host was shared with other workers, so the
session rate varied between 14,000 and 35,000 per second from run to run, and differences below a factor of two are noise.
The kernel keeps socket memory outside the resident set, so bytes_per_socket shows only the user space cost of a socket.
The draft numbers of smoltcp (1,000,584 sockets at 1.59 KB per socket, idle poll 15 to 52 ns per socket) are on the branch wp/TRN-20.
