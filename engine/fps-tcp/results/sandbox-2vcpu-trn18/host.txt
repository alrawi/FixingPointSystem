Every command is `cargo run --release -p fps-tcp --example tcp_bench -- ARGS` and was run as the built example. These are sandbox results, labelled as such. The host was shared
with other workers, so the session rate of one stack varied by up to a factor of three between runs (the kernel from 14,000 to 49,000 per second at 32 concurrent
sessions), and differences below a factor of two are noise. The text report prints the idle poll of the own stack as 0 in the small profile, because the value is
0.37 to 0.40 microseconds and the table has no decimals. The JSON has the exact value.
