Every command is `cargo run --release -p fps-tcp --example tcp_bench -- ARGS` and was run as the built example. These are sandbox results, labelled as such. Differences below a
factor of two between stacks are noise on a shared host, and the kernel rate varied from 14,000 to 45,000 per second at 32 concurrent sessions between runs.
smoltcp uses TIME-WAIT skip (a closed tuple is reused at once), a 100 ms idle poll, software checksums on, and 64 KiB socket buffers in the rate and throughput
workloads and 512 B buffers in the scaling workload, see the notes in each JSON document.
The scaling run holds 1,000,584 sockets in 64 shards (1,000,000 requested). The idle poll of 54,426 us is one poll of all 64 shards, which is 54 ns per socket.
