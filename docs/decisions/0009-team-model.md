# D9. Team model

- Status: Accepted
- Date: 2026-10-30
- Deciders: repository owner

## Context

Effort classes convert to calendar time only once we know who builds v1.

## Options

- Solo
- Small core team
- Open community from day one
- Swarm of AI coding agents (chosen)

## Decision

A swarm of AI coding agents builds v1 under owner review. Contracts land first, each agent owns one workstream, gates run as automated suites, and the owner approves gates and contract changes.

## Consequences

The specification and contracts double as the coordination layer. Review capacity at each gate bounds throughput.
