## Decisions taken in this package

- No Release button for an agent that a run holds: the controller's release ends any reservation and would take the agent from the run. The holder column still links the run.
- A 409 message is `Agent <id> was not reserved because of a conflict.` plus the problem detail, because the contract names no machine readable reason.
