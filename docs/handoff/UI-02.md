## Decisions taken in this package

- The list fetches every page with the contract maximum of 500, so the table never hides modules behind a pager. A repeated page token ends the loop.
- The query cache retries only network failures, 408, 429, and 5xx. Before, a 404 of a missing module was retried twice.
- Focus moves to the view heading only after an in app navigation (`location.key` other than `default`), so the skip link stays the first Tab stop on a fresh load.
- Component tests start one mock server per test, so the empty registry and the faults need no shared state.

## Pitfalls

- The generator puts the `$defs` of the manifest schema into the TypeScript type, so `ModuleManifest` omits `$defs`.
- `parameters` is typed as `{ type: "object" }` only, so `moduleFormat.ts` reads the rest as unknown JSON.
- A query option `retry` overrides the `retry: false` that tests pass to the QueryClient, so per query retry rules make error tests slow.
