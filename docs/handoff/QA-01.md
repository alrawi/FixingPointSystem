## Goal

We build `tests/harness/netns.sh`, which connects a client namespace and a server namespace through a routing namespace that stands in for the device under test. End to end tests then run on any Linux CI runner without virtual machines. The script offers `up`, `down`, `exec`, and `capture`, with configurable prefixes, MTU, an optional VLAN, and optional NAT in the routing namespace.
