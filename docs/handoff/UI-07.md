## Decisions taken in this package

- The suite has its own configuration `playwright.controller.config.ts` and directory `e2e-controller/`, so `npm run e2e` (mock) keeps its meaning and its speed.
- The global setup starts every process, including `vite preview`, because the controller picks free ports and the preview needs its address.
- A machine that cannot build the Go binaries fails the suite instead of skipping, because the acceptance is a passing suite in CI.
- Specs run one at a time (`workers: 1`) because they share one controller and the agent `local`, which the example configurations name.
- Runs that a report spec needs are made through REST, so the UI tests do not depend on run time.
- No exact counter values are asserted: the fake agents simulate sessions and report no histograms.

## Pitfalls

Go modules cannot be downloaded in the worker sandbox, so the controller and fake agent never build locally. The worktree guard refuses heredocs and compound git commands. A spec that edits an example file by text replacement must name the key (`scenario: http1/web_get`), because comments of the example can repeat the value. Find a checkbox that sits before its label text with `getByRole("checkbox", { name })`, not with `getByLabel` and a regular expression.
