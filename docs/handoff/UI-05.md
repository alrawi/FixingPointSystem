## Decisions taken in this package

- The comparison is built client side from two `getRunReport` calls, because the REST API has no comparison endpoint.
- Criteria pair by metric, operator, and value, in order of appearance for duplicates, because `CriterionResult` has no `where`.
- The mock's `verdictStates` option (default off) makes a run with failed criteria end in `failed`, as the controller does, without changing the UI-04 scripts that expect `completed`.
- No new dependency: tables and words, no chart.

## Pitfalls

- The sandbox worktree guard refuses shell heredocs next to git commands; write files with the editor tools or a python heredoc in its own command.
- The controller returns `realism: []` today, so the realism table is empty for real runs.
