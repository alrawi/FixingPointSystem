## Goal

Run ids get their own prefix `run_` with the character rules of the contract id pattern, so they no longer look like configuration ids. A test in `controller/internal/runs` checks that a created run id has the run prefix.

## Plan

- [x] 2. Ingest the fix into the Controller page and a log entry, run `make lint-ctl test-ctl`
