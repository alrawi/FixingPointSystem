## Goal

`strike/conn_churn` on AF_XDP failed most sessions because the own stack dropped a connection that the peer reset after the handshake and before `accept`. A kernel keeps it in the accept queue: `accept` returns it and its first read reports the reset. Fix `engine/fps-tcp-own`, then take `strike/conn_churn` off the TRN-36 exclusion list (`profiles.yaml`, the pinned test in `engine/fps-agent/src/backend.rs`).

## Done and verified

- Cause: the own client builds its reset (`RST|ACK`) before its plain ACK of the SYN-ACK is sent, so the server sees the reset while the connection is still in SYN-RECEIVED, and `on_segment` closed it without ever queueing it for the listener. Now a reset whose ACK field acknowledges our SYN-ACK completes the handshake first (queue, wake the accept), then ends the connection with `ConnectionReset`.
- Second cause found from the first CI run (`modules (strike)` failed 6 of 24): `connected` reported a reset that arrived before the connecting task looked as the error of `connect`. Fixed with the `handshook` flag in `host.rs`; the agent test in `datapath_run.rs` reproduces it without root.
- `cargo test -p fps-tcp-own`: all pass; the two new tests that drop the plain ACK fail without the fix (`accept 0 timed out`).

## Remaining

`modules (strike)` on bc5e9d69: the agent exits 0 with 47 of 47 sessions ok, conformance and parser errors pass, but `session_structure` fails 3 of 25 instances. Cause, not in the own stack: the first conn_churn instance of the run dials its churned children on 8082 before any spawned server flow has called `listen` on that port (the transport listens lazily), the own stack answers RST (`CS S.R`, port 10001), the runtime retries a refused connect of a spawned flow (`instance.rs`, by design), so host 10.1.0.1 shows 33 churn connections where the scenario allows 32 and the checker opens a phantom instance. Later instances find the port bound. Needs a decision (see PR #703 comment): pre-listen the accept ports of spawned server flows in `engine/fps-agent/src/transport.rs`/assemble, or let the structure check ignore a refused attempt that is followed by a retry.
