## Goal

Show which session did not decrypt and why; fix the cause without lowering the threshold.

## Done and verified

- From the artifact of run 46153734448: the session is 10.1.0.4:10078 to 10.2.0.1:8445 (TLS 1.2, safari-18.5, report session 79). The capture holds 6 frames of it: the SYN exchange, the ClientHello and the server flight (ServerHello, Certificate, ServerKeyExchange, ServerHelloDone). Nothing after, so tshark reads 0 of 2 Finished messages. It is the only TCP stream of 196 without a FIN or RST.
- Not the key log: the key log holds 80 sessions (CLIENT_RANDOM entries for the TLS 1.2 ones, 10 lines per TLS 1.3 session), and agent 0 wrote 73912 bytes. Agents 1 to 5 wrote 0 bytes because they ran no TLS scenario. Not the capture boundary: the session starts at 3.1 s of a 24.4 s capture. Not the reader: realism/ read what was in the file.
- The traffic happened: the agent's counters show 26 of 26 https_fetch_tls12 sessions succeeded on both sides, client tx equals server rx (6318 bytes) and server tx equals client rx (34242). The server cannot finish a handshake without the client frames, which cross wc, so tcpdump on wc lost them (a hole of about 2 ms, the next frame is 46 ms later).
- Cause: `tcpdump -s 0 -U --immediate-mode` with the default 2 MB buffer. In immediate mode the ring holds buffer / snaplen frames, here about 30 slots. A tcpdump that is not scheduled for some milliseconds on a busy runner (the agent polls AF_XDP) drops the rest of a burst. Reproduced here in two network namespaces: a stopped tcpdump with those options drops 28 of 60 frames (168 of 200 in the test), with `-s 9216 -B 65536` it drops 0. The job never printed the drop count (`tcpdump.log` is in a temp dir that the artifact leaves out), so the loss was silent.
- Fix in engine/fps-datapath/realism/module-afxdp.sh: `-s 9216 -B 65536`, and the script prints the tcpdump log and fails with "tcpdump dropped N packets" if the count is not 0 or missing. realism/ (the reader) is not at fault and not changed.
- Test engine/fps-datapath/realism/test_capture_ring.py (root, ip, tcpdump; skips otherwise): stops the tcpdump with the options of the script, sends 200 frames, needs 0 dropped. Fails with the old options (168 dropped).
