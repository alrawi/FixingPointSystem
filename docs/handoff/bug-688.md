## Goal

The hub of a datapath port in `engine/fps-agent/src/transport.rs` resets a TCP session that arrives while no call holds its host (`Port::route`). On AF_XDP the handshake is already complete, so a client that dialed a moment before the server side bound fails with `unexpected_reset` (`dns/tcp_fallback` about 1 session in 24, `hls/vod_segments` first playback). Keep such a session for `PENDING_GRACE` and give it to the next call that subscribes its host. Take both scenarios off the TRN-36 exclusion list.
