## Decisions taken in this package

- `GET /metrics` needs no token, because Prometheus scrapers usually send none and the route sits outside `/v1`.
- `wiring.Controller.Runs` is already exported, so we added no accessor and left `controller/internal/wiring/` unchanged.
- The aggregator uses the default clock and bounds, because `app.Config` has no metrics settings yet.
