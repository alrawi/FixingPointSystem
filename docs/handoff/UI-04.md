## Decisions taken in this package

- Charts are a small SVG component, not uPlot (D11 names uPlot, it is not in the lock file, jsdom has no canvas). Samples still live in a ring outside React state.
- The view reads the `application` view and sums counters over applications. Latency statistics are per application with a select.
- The stream carries only the newest tick per connection, so history and the gap after a drop come from `getRunMetrics`.
- 501 on the stream means polling, other 4xx end the feed, 401 and 403 sign out.
- The mock run follows a script on an injectable clock, and every value is a function of the tick number.

## Pitfalls

- `IncomingMessage` emits `close` when the request body ends, not when the connection closes. The mock stream listens on the response.
- The list of runs needs `staleTime: 0`, or a visit within ten seconds shows old states.
