## Decisions taken in this package

- The mock is a `node:http` server in `ui/mock/` instead of Prism. It is deterministic, adds no dependency, and runs inside Vitest. Ajv contract tests validate every response against the contract, which is the guarantee Prism would give.
- ESLint 10 as D11 names it, with an npm override of the peer range of eslint-plugin-jsx-a11y 6.10.2, whose rules we checked still fire. A second override lets openapi-typescript 7.13.0, whose peer range is TypeScript 5, run with TypeScript 6.0.3.
- The token lives in `sessionStorage`, so it ends with the tab. The sign in page checks it with `GET /capabilities` first.
- Plain semantic tables for agents and modules. React Aria tables wait for views that need sorting or selection.
- `exactOptionalPropertyTypes` stays off, because the prop types of React Aria Components reject explicit `undefined`.
- `e2e-ui` stays out of `E2E_TARGETS`, because it needs a Playwright browser and `make e2e` targets root harness tests.

## Pitfalls

- The `isPending` state of the React Aria Button leaves a live region entry that points at the unmounted button, and axe-core reports `role-img-alt`. Run axe on `document.body`, not on the render container, or the test misses it.
- `import.meta.url` is not a file URL under the jsdom environment of Vitest. Use `import.meta.dirname`.
- Set `npm_config_cache` and `TMPDIR` to a private folder when several agents share a machine.
