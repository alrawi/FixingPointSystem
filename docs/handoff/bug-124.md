## Decisions taken in this package

- `wiring.New` sets a default report handler without merged metrics, so `wiring` tests and any embedder serve reports without the aggregator, and the binary replaces it through `SetReport`, the same pattern as `SetMetrics`.
- The hook lives in `pending`, because `report.API` embeds `api.Unimplemented` and embedding it in `Server` would make every selector ambiguous.

## Pitfalls

- The orchestrator absorbs only counters without labels, so an end to end snapshot must carry unlabeled run totals for the run verdict to see them.
