## [2026-11-10] ingest | TRN-15 TLS plaintext backpressure and mail and h2 profiles

`TlsSession` no longer fails with "received plaintext buffer full". Rustls keeps at most 16 KiB of received plaintext and makes `read_tls` return an `ErrorKind::Other` error while it holds more, which a 16.5 KiB ciphertext chunk with a full record and small records behind it triggers (MOD-06, HTTP/2 frames). `poll_fill` now keeps the ciphertext that rustls refused in the session, returns to the reader so it drains the plaintext, and feeds the rest before it reads the transport again. Three new burst tests failed with the exact error before the change and pass after it, and `one_mebibyte_in_one_burst_both_ways` moves 1 MiB each way on TLS 1.3 and 1.2. `fps_module_tls::mail` adds the client profile `mail-client` (the Firefox 139 lists without ALPN) and the server profiles `server-tls13-h2` (`h2`, then `http/1.1`) and `server-tls13-noalpn`, both TLS 1.3 only and ticketless like `server-tls13` of the agent. The tests handshake six pairings and check the ALPN of both reports, and parse the ClientHello of `mail-client` to show that it has no ALPN extension. We described both changes in [Transport](Transport.md#mail-and-h2-profiles). The evidence is `docs/handoff/TRN-15.md` and `modules/tls/tests/burst.rs`.

### Shared page notes

- [Modules](Modules.md) and the READMEs of `smtp` and `imap`: the two gaps that the MOD-20 text names (a mail client profile and a mail server profile without ALPN) are closed on the TLS side. The scenarios still name `firefox-139` and `safari-18.5` for the client and `server-tls13` and `server-tls12` for the server, so they change only when AGT-16 registers `mail-client` and a server profile for mail in the agent. `server-tls13-noalpn` is the server for a mail plan.
- [Agent](Agent.md#tls-profiles): AGT-16 offers `mail-client`, `server-tls13-h2`, and `server-tls13-noalpn` through `fps_module_tls::mail` (`mail_client()`, `server_profile(name)`). The issue named only the two server profiles, so `mail-client` is a name that this package chose. The server profiles carry `ServerResumption::Disabled`, and AGT-16 sets `Tickets` on its own copy once it builds a connector per session.
- [Testing](Testing.md): the `burst` test of `fps-module-tls` runs in the `rust` job of `ci.yml` with `cargo test --workspace` and needs no tool beyond the toolchain. The `mod-tls` workflow runs only the capture test, so it does not cover the burst test.
