## [2026-11-08] ingest | CTL-15 mutual TLS between controller and agents

The package `controller/internal/pki/` gives the control channel mutual TLS. `pki.Open` generates an ECDSA P-256 controller CA on the first start and stores `ca.key` with mode 0600 in a 0700 directory, and it refuses a loose key, half a CA, a mismatched pair, or a damaged state. `NewToken` creates a single use enrollment token for one agent identity with an expiry, and the state keeps only a SHA-256 digest that the check compares in constant time. `Enroll` exchanges a valid token and a CSR for a 24 hour client certificate whose subject common name is the agent id, `Renew` replaces a certificate that the agent presents before it expires, and `Revoke` ends an identity through an allow list of issued serials, so a certificate without a record fails closed. `ServerTLSConfig` builds the gRPC server configuration with `RequireAndVerifyClientCert`, and `Handler` with `EnrollTLSConfig` serves `POST /enroll` and `POST /renew`. Tests on real TLS connections over loopback show that a fresh certificate is accepted and that no certificate, a certificate of another CA, an expired certificate, and a revoked identity are rejected, and that a reused or expired token is refused. The [Controller](../Controller.md#mutual-tls) page describes the package and the wiring that remains.

### Shared page notes

- The package is not wired into the gRPC server or the agent. The Controller page lists six changes of the controller wiring (CTL-17 owner or a follow up) and four changes of the Rust agent (AGT follow up). `agents.PeerCertIdentity` already reads the common name, so the agent manager needs no change for the identity, only a method that ends one session for `Config.OnRevoke`.
- Contract question for the owner: enrollment is served as an HTTPS endpoint of `pki`, which needs no proto change but adds an HTTP client to the agent. `Enroll` and `Renew` RPCs in `fps.agent.v1` would reuse the tonic stubs. Operators also need token and revoke operations in the OpenAPI contract, or a subcommand of the binary.
- [Testing](../Testing.md) and the Makefile: `make test-ctl-pki` and `make lint-ctl-pki` run the package alone; `make lint-ctl test-ctl` already cover it.
