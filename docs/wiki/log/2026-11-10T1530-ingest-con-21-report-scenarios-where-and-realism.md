## [2026-11-10] ingest | CON-21 Scenario totals, criterion filters, and realism results in the REST report

We added three optional parts to the run report of the REST contract. `RunReport.scenarios` lists the sessions attempted, succeeded, and failed and the bytes sent and received for each scenario of each application, `CriterionResult.where` carries the label filter of the criterion, and `RunReport.realism` now has the named schema `RealismResult` with the optional `metric` and `labels`, and a text that says where its entries come from. The controller does not measure realism: each metric of a check of the realism report of the run is one entry, and the array stays empty until the controller receives such a report, because the contract has no operation that delivers one. The owner approved the change on 2026-11-10, and every part is additive. OpenAPI moves to 0.9.0. We updated [Contracts](../Contracts.md) and the entry `contracts/changes/CON-21.md`, which lists the consumers (CTL-39, CTL-38, the UI, the SDK, the CLI, and the realism runner).
