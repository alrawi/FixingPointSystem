## [2026-11-10] ingest | CTL-41 Realism reports attached to a run

`PUT /v1/runs/{id}/realism` (`attachRealismReport`) is served by `report.API` and left the pending operations of the wiring test. It answers 404 for an unknown run, 409 for a run that has not ended, 415 for a content type other than `application/json`, 413 above 4 MiB, 400 for a body that is not one JSON document, and 422 with JSON Pointer findings when the document breaks `realism/schema/realism-report.schema.json` (an embedded byte copy that a test compares with the source), repeats a `metric` and `labels` pair, or holds a value that a 32 bit float cannot show. A valid report replaces the earlier one as a whole, a refused one leaves it, and the answer says `replaced`. `report.MapRealism` turns each metric of each check into a `RealismResult` by the mapping of CON-22 (conformance threshold and application outcome, KS alpha and comparison status, and `check passed` with the outcome of the check for every other metric, which covers the metrics of CON-23 without a change). `GetRunReport` fills `RunReport.realism` from the store, and the HTML report shows the same rows. We updated the [Controller](../Controller.md) page.
