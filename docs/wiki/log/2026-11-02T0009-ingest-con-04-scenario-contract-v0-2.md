## [2026-11-02] ingest | CON-04 Scenario contract v0.2

We extended the scenario contract to v0.2. Templates gain module function calls with keyword arguments, nested calls, float and boolean literals, and the reference `last` for the bytes that the previous `expect` of the same side consumed. On UDP one `expect` reads exactly one datagram, and the new field `max_datagram` bounds its size. Module manifests now list their template functions under `functions`, so `tools/contracts/validate.py` checks every module call and argument type without running extension code, and the engine rejects a module whose extension returns a different catalog. The [contracts README](https://github.com/alrawi/FixingPointSystem/blob/main/contracts/README.md#template-grammar) holds the grammar and the rules. We updated the seam table of [Implementation Plan](Implementation-Plan.md) and merged the duplicate Decision records and Contracts rows of [Home](Home.md). The evidence is `docs/handoff/CON-04.md` and the tests in `tools/contracts/test_contracts.py`.
