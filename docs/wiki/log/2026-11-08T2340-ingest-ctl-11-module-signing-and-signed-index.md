## [2026-11-08] ingest | CTL-11 module signing and signed index

The controller has a new package, `internal/registry/signing`, that signs and verifies module archives and a registry index with Ed25519 from the standard library. An archive signature covers the UTF-8 bytes of the module tree digest, as `ModuleRef.signature` in CON-05 defines it, and `ArchiveDigest` computes that digest from a tar archive without unpacking it. The signed index has a canonical JSON form (sorted modules, fixed key order, no escapes, a `serial` against replay) and a `SignedIndex` file. Key ids derive from the public key. A trust store keeps active, retired (verifies strictly before a cutoff), and revoked (never verifies) keys and reads and writes a JSON file of public keys. Verification fails for a modified archive or index, an unknown, revoked, or expired key, a wrong key id, and a truncated signature. Nothing calls the package yet. See [Controller](../Controller.md#module-signing-and-signed-index) for the interface, the rotation procedure, and what install, the compiler, and the agent must do.
