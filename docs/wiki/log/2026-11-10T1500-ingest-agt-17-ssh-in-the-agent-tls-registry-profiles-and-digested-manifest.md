## [2026-11-10] ingest | AGT-17 SSH in the agent, TLS profiles from the TLS module, and the digested manifest

The agent registry now holds `ssh` (MOD-11). `fps_module_ssh::Ssh` keeps the keys and packet counters of one session and is not `Clone`, so the registry holds a wrapper whose clone is a fresh `Ssh`, and the factory that the workers call for every session side gives each side a value of its own. `modules/ssh/native/examples/fixture_peer.rs` follows the same rule with one `Ssh::default()` per session. `tests/first_party.rs` runs `ssh/interactive_shell` and `ssh/scp_upload` through the agent with a real key exchange, and a session succeeds only when both sides derived equal keys, and a unit test shows that a value made after another one ran starts from nothing. `controller_e2e.sh` runs both scenarios under the real controller, one run each.

`tls.rs` no longer holds copies of `mail-client`, `server-tls13-h2`, and `server-tls13-noalpn`. `tls::client_profile` and `tls::server_profile` look them up in `fps_module_tls::mail`, and the names are the module's constants. The module's server profiles disable resumption, and `server_profile` sets stateless tickets on the agent's copy, because the agent builds one connector per session, so the tickets that the agent issued before this package are still issued. A unit test compares every field of the three profiles with the module's and checks the resumption difference. `server-tls13` and `server-tls12` stay in the agent, because the module does not register them.

`modules::load` read `manifest.yaml` twice (the catalog and the version) before the digest pass read the tree, which left the check-then-use gap that AGT-16 closed for `extension.wasm`. The digest pass now keeps the bytes of both files, and the agent parses the manifest from those bytes, so a manifest swapped after the digest is never parsed and one swapped during the pass is either the digested one or fails the digest. `modules::installed` takes name, version, and digest from one pass too. Two tests in `tests/extensions.rs` swap the manifest with the `load_with` hook (garbage and a valid manifest with another catalog) and a third flips it from a writer thread during 300 loads. The test exception that let `http2` lack a manifest is gone (`registered_with_manifest` asserts a manifest for every registered module). The evidence is `docs/handoff/AGT-17.md`.
