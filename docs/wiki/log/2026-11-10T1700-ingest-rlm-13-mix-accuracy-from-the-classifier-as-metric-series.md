## [2026-11-10] ingest | RLM-13 Mix accuracy from the classifier as metric series

The mix accuracy check of the realism runner now fills `metrics` with the catalog gauges `mix.share_pct`, `mix.abs_error_pp`, and `mix.max_abs_error_pp` for what the classifier saw in the capture, with `source` `classifier` and the classifier label (`ndpi`), validated against metric catalog 0.4.0 (CON-20). `mix.share_pct` and `mix.abs_error_pp` have one series per application of the mix, and `mix.max_abs_error_pp` has one for the run. The catalog gives the series no label for the basis, so a report carries one basis, which the new field `metrics_basis` names: `profile.basis` of the test configuration, or the only basis that ran, and `null` with an empty `metrics` when the weights come from the labels and both bases ran. The row `(unmatched)` is no application and has no series. The report format is 0.10.0 (additive: the series, `metrics_basis`, and the `rest_report` form).

The check also reads the `RunReport` of the REST API (CON-21) as a run report file. Its `scenarios` list has the application and the scenario apart, so the check joins them as `<application>/<scenario>`, takes `sessions_attempted` as the sessions and `bytes_tx` plus `bytes_rx` as the bytes, and gives the same result as the file table form of CTL-38 (`scenario` as `application/scenario`, `sessions`, `bytes`). A report without `scenarios` (a controller before API 0.9.0) is refused with that explanation, and an empty list counts nothing and fails.

Evidence: `realism/tests/fixtures/mix/` holds a committed capture of 8 HTTP sessions and 2 lookups, its labels, a test configuration of 75 and 25 percent, and the run report in both forms. `tests/test_mix.py` asserts the literal series (80 and 20 percent, errors 5.0 and a maximum of 5.0 by sessions, 73.202614 and 26.797386 percent with 1.797386 by bytes), validates the entry against the report schema and its labels and types against catalog 0.4.0, and shows that a series without `source`, with `source` `metrics`, or with another label is refused. The same series came out of a real nDPI 4.2.0 run on the fixture.
