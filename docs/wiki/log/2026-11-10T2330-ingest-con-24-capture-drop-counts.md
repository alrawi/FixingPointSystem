## [2026-11-10] ingest | CON-24 Capture drop counts in the agent protocol and the REST API

`StopCaptureResult.dropped` and `CaptureFile.dropped` counted sessions while the contract said packets, and each mixed sessions lost to a full writer queue, sessions that did not fit a ring file, and sessions open at the stop. The owner approved an additive change on 2026-11-10. `StopCaptureResult` gains the optional `dropped_overflow` (6), `dropped_oversize` (7), and `cut_at_stop` (8), `CaptureFile` gains the optional integers of the same names, and the text of `dropped` now says sessions and that it stays the sum. The protocol moves from 0.2.3 to 0.2.4 (patch number, because the controller admits agents by major and minor) and the REST API from 0.10.0 to 0.11.0. The entry `contracts/changes/CON-24.md` records the reasons, the compatibility, and the consumers. `validate.py`, `check_plans.py`, and the contract tests pass locally. `buf` and `oasdiff` are not installed in the sandbox, so `buf breaking` and `openapi-breaking` ran only in CI. The proto file compiles with `grpc_tools.protoc`.
