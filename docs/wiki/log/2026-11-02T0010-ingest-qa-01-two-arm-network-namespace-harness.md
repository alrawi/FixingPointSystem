## [2026-11-02] ingest | QA-01 Two arm network namespace harness

We added `tests/harness/netns.sh` with the commands `up`, `down`, `exec`, `capture`, and `info`. It connects a client namespace and a server namespace through a routing namespace with configurable prefixes, MTU, an optional VLAN on each arm, and optional NAT. Captures come from tcpdump in immediate mode on the router and are converted to pcapng by `tests/harness/pcapng.py`, because dumpcap dropped the last packets on stop.
